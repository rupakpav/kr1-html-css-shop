# mouseshop

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог шести мышей;
- `product.html` — описания и таблицы характеристик, якорь для каждой модели;
- `order.html` — форма заявки с выбором товара;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

### Просмотр и проверка

Откройте `index.html` в браузере

1. Проверьте общее меню на всех пяти страницах.
2. В каталоге нажмите «Подробнее»: ссылка ведёт к нужной модели в `product.html`.
3. Нажмите «Заказать»: в `order.html` должна быть выбрана соответствующая мышь.
4. На главной нажмите «Заказать» и проверьте открытие окна, закрытие кнопкой и Escape.
5. Отправьте пустую форму: она должна показать ошибки обязательных полей.
6. Заполните форму, включая телефон в формате +7 (900) 000-00-00 и согласие.
   После проверки появляется сообщение о демонстрационной отправке.
7. Проверьте фокус клавишей Tab, сетку карточек, таблицы, изображения и кнопку «Наверх».

### Самостоятельные доработки

- Единое название mouseshop и тексты по теме магазина компьютерных мышей.
- Три новые модели: Logitech G305, Razer Basilisk V3, HyperX Pulsefire Haste 2.
- Отдельные описания шести моделей, таблицы с caption, thead, tbody и заголовками scope.
- Локальные SVG-схемы мышей: это условные иллюстрации, не фотографии моделей.
- Передача выбранного товара в форму через параметр product с проверкой по списку.
- Бейджи «Новинка каталога» для новых карточек: relative и absolute.
- Боковой фильтр с position: sticky и кнопка «Наверх» с fixed и z-index.
- Общая форма с label, required, HTML-валидацией и обозначением ошибок aria-invalid.
- Уникальные title и description, единая навигация, актуальный sitemap.xml.

Все цены учебные. Данные форм не отправляются на сервер и не сохраняются.
Фильтры каталога — статический макет согласно заданию; кнопка применения отключена.
Термин «новинка» означает добавление в учебный каталог, а не дату выпуска модели.
